# CCSA Python oefeningen bij de leerstof
Programmeeringoefeningen in Python die aansluiten bij de leerstof van het opleidingsonderdeel Classic Computer Science Algorithms, ingedeeld per hoofdstuk. 

### Hoe download ik de oefeningen?
Lees [deze pagina](https://hogenttin.github.io/git-hogent-gids/readonly-repo/) voor meer informatie over het gebruik van read-only repositories.

### Oplossingen
Er is een modeloplossing voorzien voor elke oefening. Ga hier verstandig mee om!
- Wie naar de les gaat, zal de modeloplossing normaal niet nodig hebben. Alle oefeningen worden immers in de les gemaakt.
- TIAO-studenten, die de oefeningen zelfstandig maken: probeer deze eerst echt zelf te maken en gebruik de modeloplossing enkel om jouw oplossing na te kijken.
